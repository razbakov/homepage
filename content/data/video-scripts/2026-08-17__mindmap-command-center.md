# Daily — I Built a Live Map of My Entire Life System

**Source:** https://razbakov.com/blog/2026-03-25-mindmap-command-center

## Hook (0:00–0:20)

Eighteen side projects. A full-time job. OKRs. AI agents. And not a single tool that shows me how any of it connects. So I built a map — a literal map — of my entire life system. Turns out, drawing the map was the real work.

## Point 1 — The shape was missing (0:20–1:10)

Here's what I noticed. I had Notion for tasks. GitHub for code. Spreadsheets for tracking projects. Every tool answers "what should I do next?" But none of them answer a different question — the one that actually matters: how does this connect to that?

I'd open Notion, see forty cards, and feel nothing. No shape. No sense of what's central and what's a satellite. Is WeDance connected to my mission? Sure, theoretically. But where? I couldn't point to it. I couldn't see the structure of my own work.

So I built a D3.js radial tree. Mission at the center. Everything else branching out — OKRs, projects, values, key people, major decisions. Forty-nine nodes. The full picture, in one view. You can't hide from forty-nine nodes.

`[B-ROLL: Screen recording scrolling through a cluttered Notion board, then cutting to the clean radial mindmap]`
`[TEXT ON SCREEN: "Task tools show what. Not why."]`

## Point 2 — Building it is thinking (1:10–2:10)

Here's what surprised me. The act of building the map taught me more than the map itself.

Because a tree structure doesn't allow circular dependencies. If A connects to B, you have to decide — which one is the parent? That constraint forces you to commit. And commitment is where clarity lives.

I kept finding things in the wrong place. Not because the code was broken — because my mental model was fuzzy. Is WeDance an OKR or a project? It's a project, but it's the vehicle for OKR one. Which values actually drive my decisions right now? Not the aspirational ones — the real ones. Connection, autonomy, practical application. Those three show up every time.

The hardest layer was people. Adding someone to the map isn't tagging a contact. It's saying — this relationship is structural to how my work runs. That forced some honest thinking I wasn't expecting.

`[B-ROLL: Close-up of nodes being rearranged in the mindmap, dragging "values" and "people" branches]`
`[TEXT ON SCREEN: "The tree forces you to commit."]`

## Point 3 — A grounding tool (2:10–3:05)

Now I use it daily, but not the way you'd think. It's not a task manager. There are no due dates, no statuses. What it does is answer one question before I start any work: does this fit?

New project idea? New partnership? I look at the map. Does it connect to a node that's already there — or is it floating, disconnected from everything else? Disconnected usually means not now.

And when I'm context-switching between five things and losing the thread — which happens every day — I open the map. There's the center. There's where I am in it. Fifteen seconds and I'm reoriented. That's it. Fifteen seconds. That alone made the whole thing worth building.

The current version is static. I update the data file by hand. But the next step is obvious — pull live data from Notion, GitHub, my OKR tracker. Imagine the map glowing differently based on what's actually active. That's a weekend project. Maybe two.
