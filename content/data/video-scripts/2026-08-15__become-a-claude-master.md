## Point 1 — The onboarding nobody built (0:20–1:10)

Here's the problem. Claude Code is probably the most powerful developer tool I've ever used. But there's no onboarding wizard. No progressive disclosure. No little nudge that says "hey, you might want to try this." You just get dropped in. And you either stumble into the good stuff — or you don't.

I stumbled for months. Wasted hours on things that had one-line solutions. So I made a skill — one slash command — that walks you through three phases. First five minutes, it sets up your foundation. It creates a file called CLAUDE.md — the file Claude reads in every conversation. Seeds it with five rules that compound over time. After a week, Claude genuinely understands how you work. Not because it's magic. Because you taught it.

## Point 2 — It interviews you (1:10–2:10)

Phase two — the skill interviews you. Not some generic questionnaire. It asks what you actually do. Your stack. Your tools. Whether you write content, manage projects, review PRs.

Then it matches skills to your work and installs them. A frontend dev gets test-driven development and PR review tools. A content creator gets social posting and viral threads. A project manager gets workflow and estimation. You don't browse a catalog. The tool figures out what you need.

Phase three is the part I'm most excited about. There's a sixteen-topic curriculum built in. Prompting patterns. The memory system. Hooks. Multi-agent workflows. Each session is about fifteen minutes. Claude fetches the latest docs, teaches the concept, gives you a challenge, records your score. It's structured learning — inside the tool you're learning about.
